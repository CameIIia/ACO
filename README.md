# 蚁群算法求解旅行商问题 (ACO for TSP)

本项目通过 Python 实现了蚁群优化 (Ant Colony Optimization, ACO) 算法，用于解决经典的旅行商问题 (Traveling Salesman Problem, TSP)。

代码 `aco_tsp_solver.py` 结构清晰，并附有详细的中文注释，旨在帮助用户（特别是教学场景下的学生）理解算法的每一个核心步骤。

## 文件结构

```
.
├── aco_tsp_solver.py       # 算法核心实现与主程序
├── city_distribution.png   # 初始城市分布图
├── aco_tsp_result.png      # 算法找到的最优路径图
├── yiqun.md                # 算法背景与伪代码（教学材料）
└── README.md               # 本文档
```

## 如何运行

直接在终端中运行 Python 脚本即可：

```bash
python aco_tsp_solver.py
```

脚本会执行以下操作：

1.  **输出城市坐标**：在控制台打印预定义的城市坐标。
2.  **生成城市分布图**：创建 `city_distribution.png` 文件，展示初始的城市布局。
3.  **执行ACO算法**：
    *   在前三次迭代中，为教学目的详细打印第一只蚂蚁选择下一个城市时的概率计算过程。
    *   在后续迭代中，每10次迭代报告一次当前的路径长度和全局最优路径长度。
4.  **输出最终结果**：在控制台打印找到的最优路径和其总长度。
5.  **生成最优路径图**：创建 `aco_tsp_result.png` 文件，可视化展示找到的最短路径。

## 代码结构与算法步骤详解

代码主要分为 `AntColonyOptimization` 类和主程序两大部分。我们将根据代码中的步骤注释来详细解读。

### 步骤A: 初始化 (`__init__`)

这是算法的起点。在此步骤中，我们进行以下初始化工作：

-   **存储核心参数**：如蚂蚁数量 (`num_ants`)、迭代次数 (`num_iterations`)、信息素蒸发率 (`decay`) 等。
-   **初始化信息素矩阵 (`pheromone`)**：创建一个 N x N 的矩阵（N为城市数量），并将所有路径上的初始信息素浓度设为一个常数（通常为1）。
-   **计算启发式信息矩阵 (`heuristic`)**：同样是一个 N x N 矩阵。启发式信息通常是距离的倒数 (`η = 1/d`)，表示从一个城市到另一个城市的“渴望程度”。距离越短，启发式信息值越大。
-   **初始化最优解记录**：设置一个变量来存储迄今为止发现的最短路径及其长度。

### 步骤B: 算法主循环 (`run`)

这是算法的核心驱动部分，它控制着整个迭代过程。

1.  **迭代**：在一个大的循环中，模拟蚂蚁群的一次次“觅食”过程。
2.  **构建路径**：在每次迭代中，调用 `_construct_solutions` 方法，让每一只蚂蚁都独立地构建一条完整的路径。
3.  **更新信息素**：所有蚂蚁都完成路径构建后，调用 `_update_pheromone` 方法来更新全局的信息素矩阵。
4.  **记录最优解**：比较本次迭代中找到的最优路径与全局最优路径，如果找到了更短的路径，则更新全局最优解。

### 步骤C: 构建路径 (`_construct_solutions`)

此方法模拟了所有蚂蚁寻找路径的过程。

-   **为每只蚂蚁构建路径**：对于蚁群中的每一只蚂蚁：
    1.  随机选择一个起始城市。
    2.  根据**轮盘赌选择法**和概率公式，逐步选择下一个未访问的城市，直到所有城市都被访问过。
    3.  将路径的起点和终点连接起来，形成一个闭环。
    4.  计算该路径的总长度。
-   **教学输出**：为了教学目的，在前三次迭代中，会详细打印出第一只蚂蚁在选择第一个目的地城市时的完整概率计算过程，展示信息素和启发式信息是如何共同作用的。

### 步骤D: 根据概率选择下一个城市 (`_select_next_city`)

这是蚁群算法决策的核心，体现了随机性与确定性的结合。

1. **计算概率**：对于当前城市，计算前往每一个未访问过的邻近城市的概率。该概率由以下公式决定：

   $P_{ij} = \frac{[\tau_{ij}]^\alpha \cdot [\eta_{ij}]^\beta}{\sum_{k \in \text{allowed}} [\tau_{ik}]^\alpha \cdot [\eta_{ik}]^\beta}$

   其中 `τ` 是信息素浓度，`η` 是启发式信息，`α` 和 `β` 分别是它们的重要性因子。

2. **轮盘赌选择**：根据计算出的概率分布，随机选择下一个城市。概率越高的城市被选中的机会越大。

### 步骤E: 更新信息素 (`_update_pheromone`)

这是算法实现“学习”和“正反馈”的关键步骤。

1. **信息素蒸发 (Evaporation)**：所有路径上的信息素都会以一定的速率 `decay` (ρ) 蒸发掉一部分。这有助于避免算法过早陷入局部最优解，增加了探索新路径的可能性。

   `τ_new = (1 - ρ) * τ_old`

2. **信息素增强 (Enhancement)**：所有蚂蚁根据自己构建的路径长度，在路径上留下信息素。路径越短，留下的信息素越多。

   `Δτ = Q / Lk` (其中 Q 是常数, Lk 是第k只蚂蚁的路径长度)

   这样，较短的路径会获得更多的信息素积累，从而在后续迭代中吸引更多的蚂蚁。

### 步骤F-I: 主程序

主程序部分负责设置问题、运行算法并展示结果。

-   **步骤F: 定义问题**：定义城市的坐标，并计算出城市间的欧几里得距离矩阵。
-   **步骤G: 设置ACO超参数**：配置算法的所有参数，如 `alpha`, `beta`, `decay` 等。这些参数的调整对算法性能有重要影响。
-   **步骤H: 运行ACO并输出结果**：实例化 `AntColonyOptimization` 类，调用 `run` 方法执行算法，并在控制台打印最终找到的最优路径和长度。
-   **步骤I: 可视化结果**：使用 `matplotlib` 库绘制找到的最优路径，并将其保存为 `aco_tsp_result.png`。
